# Security policy

If you find a security vulnerability in a The Stack Hub repository, please report it privately. Do not open a public issue or pull request.

## Preferred: GitHub private reporting

Use GitHub's private vulnerability reporting, or open a draft security advisory on the repository (Security → Advisories). Maintainers will be notified without a public disclosure.

See [Privately reporting a security vulnerability](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately) and [Repository security advisories](https://docs.github.com/en/code-security/security-advisories/working-with-repository-security-advisories/about-repository-security-advisories).
