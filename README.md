# The Stack Hub organization defaults


Public [`.github`](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) repository for [The-Stack-Hub](https://github.com/The-Stack-Hub).


- `profile/README.md` appears on the organization's public Overview.
- Community health files here are used by any organization repository that does not define its own.
- This repository **must stay public** or the profile README and default files will not apply.
- Owner setup notes are kept privately.
