# The Stack Hub

**The Stack Hub Pvt. Ltd.** · Pune, India

The Stack Hub is an AI/ML and data engineering studio. We build production machine learning, LLM applications, and the data platforms behind them — then ship them as products.

[thestackhub.com](https://www.thestackhub.com/) · [arti.shinde@thestackhub.com](mailto:arti.shinde@thestackhub.com)

## Products

- **[Typeglass](https://typeglass.com)** — Select text or an image and act in one click, in the other person's language. Reply, translate, rewrite, or turn what you can see into editable text and diagrams. You review every result; Typeglass never sends it.
- **[DistributeIQ](https://distributeiq.com)** — Warehouse to doorstep, one connected system. Orders, trips, invoices, crates, and collections in one place; drivers work the route offline and the back office sees every stop when they sync.
- **[FrameSleuth](https://framesleuth.com)** — Practice and classwork for Maharashtra Classes XI and XII Science Information Technology, in Marathi and English. Teachers run the class; students do the next useful practice; the school controls accounts and access.
